## FAILURE-CLOSED BEHAVIOR

The graph validator fails closed when:

- dependency ID is missing
- cycle exists
- duplicate job ID exists
- duplicate idempotency key exists
- job is marked ready while dependencies are unresolved

The unlock engine fails closed when:

- graph validation fails
- dependency is missing
- dependency is `hard_hold`
- dependency is `failed_terminal`
- dependency is not `approved`
- job state is not `planned` or `waiting_dependency`
