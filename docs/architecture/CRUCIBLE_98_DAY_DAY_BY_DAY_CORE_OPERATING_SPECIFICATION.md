## 1. Purpose
Define the exact operating role of every Crucible day from Day 1 through Day 98 while keeping academic allocation adaptive, evidence-bound, mission-specific and fully traceable from verified syllabus to DigiBook teaching to question attempts and downstream Test Arena.

## 2. Fixed Cycle Law
98 days = 7 phases x 14 days.
Day 98 wraps to Day 1 under the next-cycle policy.
Micro and Macro are Crucible constructs.
Major Test is not a Crucible construct and belongs to Test Arena.

## 3. Fourteen-Day Phase Constitution
Days 1-12: scheduled teaching/practice frontier with six every-second-day Micro checkpoints.
Day 13: REBUILD DAY. No new scheduled syllabus allocation.
Day 14: MACRO INTEGRATION DAY. No ordinary new syllabus allocation before the Macro.
This governance rhythm repeats seven times.

## 4. Micro Cadence
Micro checkpoints occur on relative phase Days 2, 4, 6, 8, 10 and 12.
Therefore global Micro days are:
2,4,6,8,10,12;
16,18,20,22,24,26;
30,32,34,36,38,40;
44,46,48,50,52,54;
58,60,62,64,66,68;
72,74,76,78,80,82;
86,88,90,92,94,96.

Total Micro checkpoints per 98-day cycle = 42.

## 5. Rebuild Cadence
Global Rebuild Days:
13, 27, 41, 55, 69, 83, 97.
Total = 7.

No new scheduled syllabus atom/topic is introduced on a Rebuild Day.

## 6. Macro Cadence
Global Macro Days:
14, 28, 42, 56, 70, 84, 98.
Total = 7.

Macro is a phase integration/retention assessment, not a concatenation of six Micros.

## 7. Schedule Unit
A schedule is not defined by a fixed number of topics.
Its smallest academic planning boundary is derived from verified mission syllabus -> DSD/atoms -> teacher/pedagogy workload -> released DigiBook teaching units -> available learner capacity/time.

A schedule may contain one topic, part of a topic, multiple micro-topics, multiple atoms or a bounded cross-topic teaching set when the Mission Blueprint and pedagogy justify it.

## 8. Schedule Capacity Compiler
For each scheduled day, compile an Academic Workload Envelope from:
mission blueprint
current syllabus frontier
atom dependency/prerequisite graph
pedagogy effort
DigiBook unit size/depth
student entry class
current taught state
unresolved repair debt
retention debt
available study capacity
mission/exam constraints

Calendar convenience cannot split an academically indivisible unit unsafely or force excessive content.

## 9. No Universal Topic Count
There is no constitutional rule such as "N topics per day."
Topic count is a derived display statistic, not planning authority.
Atomic workload and learning coherence govern allocation.

## 10. Day Package
A scheduled learning day can produce:
Core Learning Package
Carry-Forward Repair Package
Retention Recall Package where policy calls for it
Practice Package
Evidence Requirements
Next-Micro Eligibility Frontier

All content must reference exact released DigiBook/pedagogy/syllabus authority.

## 11. Same-Day Assessment Safety
A Micro may run on a day that also has scheduled teaching, but a question is eligible only if all required substantive knowledge was inside the valid Taught Manifest-derived Knowledge Boundary before the applicable assessment eligibility cut-off.

Calendar presence does not make same-day content testable.

## 12. Micro Purpose
Each Micro is a short diagnostic pulse, not a mini major exam.
It measures a bounded mixture of:
recent eligible knowledge
unresolved weakness
retention probes
exam-relevant reasoning/difficulty within scope

Its purpose is to produce actionable evidence for the next learning block.

## 13. Micro Size Policy
No universal question count is hard-coded across missions.
Each Mission Blueprint defines a bounded Micro policy:
minimum/maximum question count
target duration
coverage floor
recent/weak/retention allocation rules
difficulty/cognitive distribution
subject/component constraints
question-family/repetition constraints
stop/extension rules if any

Adaptive selection operates only inside that approved envelope.

## 14. Micro Selection Inputs
Selection uses:
current Knowledge Boundary
eligible question pool
QuestionID/version/dependencies
recent taught frontier
previous Micro errors
misconception patterns
repair status
retention age
difficulty/calibration confidence
recent exposure/repetition
mission blueprint

No eligible questions => explicit coverage gap; never widen scope.

## 15. Micro Output
Every Micro produces immutable attempt evidence and a Diagnostic Delta:
correct/incorrect/partial/skip
QuestionID/version
knowledge dependencies
AtomID/MicroTopic/Topic/Subject/Mission lineage
response/scoring
time where meaningful
difficulty/cognitive metadata
misconception/error classification where supported
confidence/reliability state
resulting weakness/retention signals

Score alone is insufficient output.

## 16. Carry-Forward Repair
The next scheduled learning block consumes the prior Micro Diagnostic Delta.
Repair may route to exact DigiBook units, explanation units, prerequisite recall, misconception repair, worked examples or bounded practice.

Repair cannot introduce unauthorized knowledge and cannot falsely mark material taught; Teaching Execution rules govern evidence.

## 17. Day 13 Rebuild Constitution
Day 13 has no new syllabus schedule.
It compiles evidence from:
six phase Micros
Days 1-12 Teaching/Taught evidence
repair attempts
retention signals
unresolved prerequisite debt
misconception recurrence
difficulty-band behavior
question exposure/family history

It generates a personalized Rebuild Plan only from authorized/released material and eligible repair content.

## 18. Rebuild Plan
A Rebuild Plan may include:
targeted DigiBook revisit
prerequisite recall
misconception repair
worked example
representation repair
formula/procedure repair
guided practice
fresh equivalent practice
short verification probes

It must identify exact Atom/MicroTopic/Objective dependencies and reason for inclusion.

## 19. Rebuild Is Not Micro Seven
Day 13 verification probes are repair evidence, not a seventh Micro.
They must not distort Micro cadence/statistics.

Exact prior questions need not be repeated. Fresh equivalent questions are preferred when memorized-answer contamination would weaken evidence.

## 20. Day 14 Macro Constitution
Macro evaluates the phase's valid accumulated knowledge using broader integration and retention.
It can combine:
phase knowledge coverage
retention
cross-topic/atom integration
unresolved weakness sampling
exam-relevant cognitive demand
representative strong-area sampling

Macro cannot test untaught knowledge merely because it belongs to the phase syllabus plan.

## 21. Macro Size Policy
No universal Macro question count is constitutional.
Mission Blueprint defines bounded Macro:
question-count/duration envelope
coverage breadth
subject/component distribution
integration requirement
retention requirement
difficulty/cognitive distribution
weakness sampling rule
scoring policy
question-family/repetition/security constraints

Macro is normally broader than Micro by role; exact size is mission-derived.

## 22. Macro Output
Macro produces:
phase score/scoring detail
QuestionID-level attempt evidence
atom/micro-topic/topic/subject performance
retention evidence
integration evidence
persistent weakness
rebuild effectiveness
difficulty-band behavior
coverage confidence
phase-state transition inputs

Macro score never replaces granular evidence.

## 23. Phase State Freeze

current valid strengths/weaknesses
retention debt
unresolved repair debt
current Knowledge Boundary
policy/version fingerprints

This becomes an input to the next phase.

## 24. Cross-Phase Carry
Phases are not independent resets.
Phase N+1 allocation consumes:
current syllabus frontier
Phase N Macro
unresolved weakness
retention debt
valid taught authority
entry-class policy
mission blueprint/capacity

Old weaknesses may continue across phases until repaired or policy-classified.

Internal authority IDs remain hidden from normal student UX.

## 26. Smart Entry
Smart Entry may classify Novice/Middle/Pro according to separately versioned policy before/at cycle entry.
It may affect pacing/scaffolding/workload envelope, but cannot change canonical syllabus truth or bypass prerequisite/taught authority.

## 27. DigiBook Linkage
Every scheduled teaching/remediation item references exact DigiBook material version and underlying atom/objective/pedagogy authority.
Crucible never owns a divergent teaching copy.

## 28. Question Repository Linkage
Every Micro/Macro question references canonical QuestionID + semantic version/appearance + closure proof.
Selection never creates ungoverned duplicate question content.

## 29. Attempt-to-Knowledge Trace
Required trace:
StudentAttemptID -> QuestionID -> QuestionVersion -> KnowledgeDependencyID -> AtomID -> MicroTopic/Topic -> Subject -> Mission.

Where hierarchy differs by mission, canonical DSD lineage replaces assumed labels while preserving traceability.

## 30. Student Progress Trace
Progress is computed from evidence over exact dependencies, not only aggregate test score.
A student can be strong in one atom and weak in another within the same topic.
Topic/subject summaries are derived roll-ups.

## 31. Question Analytics
Stable QuestionID/version supports:
attempt count
correct/incorrect/partial/skip
response distribution
time metrics where meaningful
empirical difficulty
discrimination/calibration where valid
misconception/distractor behavior
population/context segmentation under policy

Semantic versions are not statistically conflated without validated equivalence.

## 32. Estimated Versus Empirical Difficulty
Estimated difficulty is pre-data metadata.
Empirical difficulty is derived from sufficient valid response data under version/context-aware calibration.
Author/AI label never overwrites empirical evidence.

## 33. Micro Adaptation Boundary
Adaptive selection may change question composition and bounded workload, not syllabus authority.
It cannot expand beyond Mission Blueprint, current verified scope or Taught Boundary.

## 34. Repetition Control
Question repetition policy distinguishes:
intentional recheck
spaced retrieval
unintended duplicate
family sibling
memorization risk

Equivalent fresh items may be selected for repair verification when exact repeat would contaminate evidence.

## 35. Retention Debt
Previously taught knowledge can accrue retention debt based on elapsed time, prior confidence, errors and policy.
Retention debt influences future Micro/Macro selection but does not by itself mark knowledge untaught.

## 36. Weakness State
Weakness is evidence-derived and versioned.
Possible conceptual states:
NEW_SIGNAL
REPEATED
UNDER_REPAIR
RECHECK_DUE
REPAIRED
PERSISTENT
STALE_EVIDENCE

Exact runtime representation may be simpler if reconstructability is preserved.

## 37. Mastery Caution
Crucible attempts can inform learner models, but TAUGHT != MASTERED.
This specification does not create a universal mastery algorithm without a separately validated policy.

## 38. Test Arena Linkage
Major Test remains Test Arena.
Crucible exports phase/cycle evidence, current Knowledge Boundary and learner diagnostic state.
Test Arena consumes only what its own mode/blueprint permits and never rewrites Crucible/Taught truth.

## 39. Major-Test Separation
No Day 14/28/42/56/70/84/98 Macro is renamed Major Test.
Major Test scheduling, full-exam simulation and other Test Arena modes remain outside Crucible.

## 40. Cycle Completion
Day 98 Macro completes Phase 7 and the 98-day cycle evidence package.
Cycle completion records:
seven Phase States
42 Micro checkpoints
7 Rebuild Days
7 Macros
teaching/repair coverage
current diagnostic state
retention debt
Knowledge Boundary
cycle policy/version

## 41. Day 98 to Day 1 Wrap
Wrap does not erase history.
Next Day 1 uses a new cycle identity and carries forward only policy-authorized current state/evidence.
No learner is reset to unknown merely because calendar wraps.

## 42. Calendar Versus Academic Frontier
If academic delivery is delayed/interrupted, calendar position cannot falsely claim content taught.
Policy decides pause/resume/re-entry behavior.
Assessment remains bounded by actual current Taught Boundary.

## 43. Missed Micro
A missed Micro is recorded as missing diagnostic evidence, not automatic academic failure.
Policy may reschedule, skip with reduced confidence, or route catch-up without duplicating authority.
No fabricated attempt.

## 44. Missed Rebuild
Missing Day 13 leaves repair debt explicit.
It cannot be silently marked complete because Day 14 arrives.

## 45. Missed Macro
Macro absence leaves phase integration evidence incomplete.
Next-phase entry policy must explicitly define whether learning may continue and with what confidence/repair state.

## 46. Fail-Closed Conditions
Block affected selection when:
question closure stale
Taught Boundary insufficient
wrong mission/track
question security hold
invalidated upstream content
unresolved required media/answer
policy missing
no eligible question pool

Return typed gap, never silently broaden scope.

## 47. Idempotency and Concurrency
Schedule compilation, question selection, attempt submission, scoring, diagnostic delta, Rebuild Plan and Phase State publication require stable identities/idempotent handling.
Retries cannot create duplicate attempts or conflicting effective phase truth.

## 48. Offline/Delayed Evidence
Delayed attempts/teaching evidence can trigger deterministic recompilation where policy permits.
Prefer temporarily incomplete state over false progress.
Historical states are superseded, not rewritten.

A policy change does not retroactively rewrite historical learner events.
